# Social Tabs 4.0.5 — загрузка изображений X без Referer

Эта версия добавляет `referrerpolicy="no-referrer"` к изображениям публикаций X. Браузер не передаёт сайту изображений адрес страницы Joomla, с которой загружена картинка. Атрибут задаётся в HTML перед `src`, до начала загрузки.

Ссылка `https://pbs.twimg.com/media/HJT4Tp9XIAQBe9L.jpg` открывается у пользователя напрямую, но картинка не загружается внутри модуля. Это обновление проверяет вероятную причину сбоя. Факт блокировки по Referer на действующем сайте пока не подтверждён. При другой причине отказа эта правка сама по себе её не устранит.

## Установка

1. Скачайте `mod_social_tabs_Joomla5_6_v4.0.5_x_image_referrer.zip`.
2. В Joomla откройте «Система → Установка → Расширения» и установите ZIP поверх текущего Social Tabs 4.0.4. Предварительно удалять модуль не нужно.
3. Очистите кеш Joomla, включая кеш страниц и модулей, и обновите страницу сайта.
4. Откройте вкладку X и проверьте изображения.

Это установочный пакет модуля, в отличие от предыдущих файлов переопределений JUX. Настройки, токены, алгоритм X API и кеш ленты не изменялись. Повторно вводить токены не требуется. Изображения Facebook, Instagram, YouTube и RSS используют прежний режим загрузки.

Если картинки по-прежнему не отображаются, нужен текст ошибки запроса изображения из вкладки браузера «Сеть / Network» или «Консоль». Доступ к `pbs.twimg.com` из рабочей среды разработки ограничен сетевым прокси, поэтому ответ этого сервера при встраивании здесь не проверен.

## Проверка

Синтаксис изменённых PHP-файлов проверен на PHP 8.4. Проверена фактическая HTML-разметка для всех пяти сетей: атрибут добавляется только к изображениям X, URL картинок и атрибуты отложенной загрузки сохраняются. Из файлов версии 4.0.4 изменены только шаблон изображения и метаданные версии/ресурсов. На действующем сайте обновление не устанавливалось.
