Это переопределение шаблона, не установочный пакет Joomla.

1. Сохраните копию текущего templates/g5_helium/html/mod_jux_news_wall/default.php.
2. Замените этот файл приложенным default.php.
3. В настройках News Wall оставьте Lightbox выключенным.
4. Очистите кеш Joomla (страниц и модулей), затем проверьте главную, фильтры, «показать ещё» и отдельную статью с галереей.

При Lightbox=0 скрытые полные статьи не формируются. Стандартные обложки и вызов WebP-оптимизатора сохранены. При Lightbox=1 используется штатный шаблон модуля. OS Gallery и её настройки не меняются.

Файл проверен изолированно на PHP 8.4; на действующем сайте не устанавливался.
